# APDU 指令参考

## SELECT MF (Master File)

**APDU:** `00 A4 00 00 02 3F00`

| 字节 | 值 | 说明 |
|------|-----|------|
| CLA | 00 | 命令类别 |
| INS | A4 | SELECT 指令 |
| P1 | 00 | 选择方式：选择 MF |
| P2 | 00 | 无特殊处理 |
| Lc | 02 | 数据长度 |
| Data | 3F00 | MF 文件标识 |

**期望响应:** SW = 9000

---

## SELECT EF_ICCID

**APDU:** `00 A4 00 00 02 2FE2`

| 字节 | 值 | 说明 |
|------|-----|------|
| CLA | 00 | 命令类别 |
| INS | A4 | SELECT 指令 |
| P1 | 00 | 选择方式：选择 DF |
| P2 | 00 | 无特殊处理 |
| Lc | 02 | 数据长度 |
| Data | 2FE2 | ICCID 文件标识 |

**期望响应:** SW = 9000

---

## READ BINARY

**APDU:** `00 B0 00 00 0A`

| 字节 | 值 | 说明 |
|------|-----|------|
| CLA | 00 | 命令类别 |
| INS | B0 | READ BINARY 指令 |
| P1 | 00 | 偏移量高字节 |
| P2 | 00 | 偏移量低字节 |
| Le | 0A | 期望读取长度（10 字节） |

**期望响应:** SW = 9000，数据为 10 字节 ICCID

---

## 状态字 (SW) 参考

| SW | 说明 |
|----|------|
| 9000 | 成功 |
| 6A82 | 文件未找到 |
| 6700 | 长度错误 |
| 6E00 | 不支持的指令 |
