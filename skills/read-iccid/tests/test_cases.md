# 测试用例

## 测试用例 1：正常读取 ICCID

**描述:** 测试完整的 ICCID 读取流程

**前置条件:**
- 读卡器已连接
- SIM 卡已插入

**测试步骤:**
1. 发送 `skill.init` 请求
2. 发送 `skill.start` 请求
3. 发送 SELECT MF 的 ActionResult (SW=9000)
4. 发送 SELECT EF_ICCID 的 ActionResult (SW=9000)
5. 发送 READ BINARY 的 ActionResult (SW=9000, data=986810325476981032F3)

**期望结果:**
- 最终状态为 SUCCESS
- 返回的 ICCID 以 "89" 开头
- ICCID 长度为 19-20 位数字

---

## 测试用例 2：SELECT MF 失败

**描述:** 测试 SELECT MF 指令失败的情况

**前置条件:**
- 读卡器已连接
- SIM 卡未插入或无法读取

**测试步骤:**
1. 发送 `skill.init` 请求
2. 发送 `skill.start` 请求
3. 发送 SELECT MF 的 ActionResult (SW=6A82)

**期望结果:**
- 返回 FAILED 状态
- 错误码为 APDU_STATUS_ERROR

---

## 测试用例 3：BCD 解析 - 带填充位

**描述:** 测试 BCD 编码解析，包含填充位 F

**输入数据:**
```
hex: 98 68 10 32 54 76 98 10 32 F3
```

**期望输出:**
```
ICCID: 898601234567890123
```

**验证点:**
- 正确解析低 4 位和高 4 位
- 遇到 F 时停止解析
- 结果为纯数字字符串

---

## 测试用例 4：会话状态保持

**描述:** 测试多轮交互中会话状态正确保持

**测试步骤:**
1. 初始化会话
2. 执行 SELECT MF，验证状态为 WAIT_SELECT_ICCID
3. 执行 SELECT EF_ICCID，验证状态为 WAIT_READ_BINARY
4. 执行 READ BINARY，验证状态为 SUCCESS

**期望结果:**
- 每次状态转换正确
- sessionId 保持一致
- 最终数据包含解析后的 ICCID

---

## 测试用例 5：错误恢复

**描述:** 测试在中间步骤失败后的状态

**测试步骤:**
1. 初始化会话
2. 执行 SELECT MF 成功
3. 执行 SELECT EF_ICCID 失败 (SW=6A82)

**期望结果:**
- 状态变为 FAILED
- 错误信息包含 SW 状态字
- 会话数据记录失败状态

---

## 测试用例 6：不同运营商 ICCID

**描述:** 测试解析不同运营商的 ICCID

| 运营商 | 国家代码 | 运营商代码 | 示例 ICCID |
|--------|----------|------------|------------|
| 中国移动 | 86 | 00 | 898600... |
| 中国联通 | 86 | 01 | 898601... |
| 中国电信 | 86 | 02 | 898602... |
| 美国 | 01 | - | 8901... |

**验证点:**
- 正确识别国家代码
- 正确识别运营商代码
- 解析结果为有效 ICCID
